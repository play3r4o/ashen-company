# Ashen Company — High Quality Settings UI Replacement

## Install

Extract this ZIP into the root folder containing `project.godot`.

It will add:

`res://assets/ui/ashen_hq/settings/`

and:

`res://docs/LUNA_MAX_SETTINGS_HQ_REPLACEMENT_PROMPT.md`

The pack does not overwrite the previous UI pack.

## Use

1. Commit the currently working Settings redesign.
2. Extract this ZIP into the repository root.
3. Give Luna Max the replacement prompt.
4. Luna must change only visuals and spacing.
5. Test all Settings behavior before committing.

## Important

The full modal frame is a fixed-size 354x724 production texture designed for
the current 390x844 portrait viewport. Do not use it as a nine-slice texture.
